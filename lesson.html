HTML কী?

HTML এর পূর্ণরূপ হলো HyperText Markup Language। এটি ওয়েব পেজের মূল কাঠামো তৈরি করতে ব্যবহৃত হয়।

একটি ওয়েবসাইটে Heading, Paragraph, Image, Link, Button ইত্যাদি যোগ করার জন্য HTML ব্যবহার করা হয়।

মনে রাখবে: HTML কোনো Programming Language নয়। এটি একটি Markup Language।

প্রথম HTML কোড

নিচে একটি সাধারণ HTML ডকুমেন্টের উদাহরণ দেওয়া হলো।

index.html 
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My First Website</title>
</head>
<body>
    <h1>Hello World!</h1>
    <p>Welcome to my website.</p>
</body>
</html>

কোডের ব্যাখ্যা

<!DOCTYPE html>

ব্রাউজারকে জানায় যে এটি HTML5 ডকুমেন্ট।

<html>

HTML ডকুমেন্টের মূল Element।

<head>

পেজের Metadata এবং Title এখানে থাকে।

<body>

ওয়েবসাইটে দৃশ্যমান সব Content এখানে থাকে।
